title: Q39.Combination Sum
date: 2026-06-02 11:06:42
categories:
- LeetCode
tags:
- Backtracking
- Medium

Description

Given an array of distinct integers candidates and a target integer target, return a list of all unique combinations of candidates where the chosen numbers sum to target. You may return the combinations in any order.

The same number may be chosen from candidates an unlimited number of times. Two combinations are unique if the frequency of at least one of the chosen numbers is different.

The test cases are generated such that the number of unique combinations that sum up to target is less than 150 combinations for the given input.

Example 1:

Input: candidates = [2,3,6,7], target = 7
Output: [[2,2,3],[7]]
Explanation:
2 and 3 are candidates, and 2 + 2 + 3 = 7. Note that 2 can be used multiple times.
7 is a candidate, and 7 = 7.
These are the only two combinations.
Example 2:

Input: candidates = [2,3,5], target = 8
Output: [[2,2,2,2],[2,3,3],[3,5]]
Example 3:

Input: candidates = [2], target = 1
Output: []

Approach

The first solution came into my mind when I saw it is a combination question is backtracking, use backtracking can easily spread out all possible combination as a tree, and trim the branch that don’t meet the requirement to save time and space.
So here’s how I figure out my solution:

  1. first think of this as a tree, we spread out by adding one element.
  2. when should we stop the recursion?
    1. if the sum up of the combination equal -> we should add this combination to our final answer.
    2. if the sum up of the combination and the current element already exceed the target -> we should skip this element, try next element(because the question didn’t mention the array is sorted).
  3. we only want unique combination, and we are using backtracking, it means when we tried out all combination from index 0 - n, all posssible combination that contains element[0] are tested, so in next recursion we only need to try combination from index 1 - n, in this way we avoid duplicate combination. -> we need the index from previous recursion.

Code (Java)

class Solution {
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        List<List<Integer>> result = new ArrayList<>();
        backtracking(candidates, target, 0, 0, new ArrayList<Integer>(), result);
        return result;
    }

    private void backtracking(int[] candidates, int target, int sum, int prevIndex, List<Integer> combination, List<List<Integer>> result) {
        if (target == sum) {
            result.add(combination);
            return;
        }

        for (int i = prevIndex; i < candidates.length; i++) {
            if (candidates[i] <= (target - sum)) {
                List<Integer> copiedCombination = new ArrayList<>(combination); 
                copiedCombination.add(candidates[i]);
                backtracking(candidates, target, sum + candidates[i], i, copiedCombination, result);
            }
        }
    }
}
